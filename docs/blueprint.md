# **App Name**: Gopalganj Swasthya Seva

## Core Features:

- Doctor Directory: Display a comprehensive list of doctors in Gopalganj, Bihar, India, including their specializations and consultation charges. Show a link to display location via Google Maps.
- Appointment Booking: Enable patients to book appointments with listed doctors, specifying the preferred date and time.
- Appointment Routing: Route appointment requests to the doctor's compounder for approval and scheduling.
- Appointment Display: Present a clear display of available appointment slots, including date, time, and location details.
- Helpline Integration: Provide a prominent display of the helpline number (9771264784) for immediate assistance.
- AI-Powered Specialization Summaries: Implement an AI tool to generate summaries of doctor specializations based on their listed expertise.

## Style Guidelines:

- Primary color: Sky Blue (#87CEEB), suggesting health and trustworthiness.
- Background color: Light off-white (#F5F5F5) to ensure readability and a clean interface.
- Accent color: Teal (#008080) for interactive elements and call-to-action buttons to draw attention.
- Font: 'PT Sans', a modern sans-serif font for a clean and accessible reading experience.
- Use universally recognized health icons in a flat, minimalist style.
- Ensure a mobile-responsive design with clear sectioning and a user-friendly interface.
- Subtle transition effects during navigation to enhance user experience.
